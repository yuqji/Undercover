# Undercover（谁是卧底）· 在线多人版

网页游戏：每个人在自己的电脑或手机浏览器里打开网址，通过链接、二维码或 4 位房间码加入同一个房间。大部分人拿到同一个词，卧底拿到一个相近的词，而且不知道自己是卧底。可以选择加入 Mr. White（什么词都没有）。
**全程自动，不需要主持人。**

## 游戏怎么跑

| 环节 | 自动规则 |
|---|---|
| 开局 | 所有人点 **Ready**，人数够了就自动倒数 3 秒开始。建房的人是"房主"，只负责选设置；改设置会把大家的 Ready 重置，免得有人被拉进自己没同意的设置 |
| 发言 | 随机顺序，**谁都可能第一个**。每人 **45 秒**打一个词，超时自动跳过；掉线的人轮到时只等 8 秒 |
| Mr. White 第一个发言 | 系统只给他一个**类别提示**（比如 "Animals"），其他人看不到 |
| 投票 | 统一 **30 秒**。**投票保密**：只显示"几个人已投"，看不到谁投了谁。倒计时内可以随时改票；所有人都投完后剩 5 秒最后改票时间，然后自动计票 |
| 结果 | 只公布票数，不公布谁投了谁。最高票出局；平票时只在平票的人之间重投一次，再平就本轮没人出局。8 秒后自动进入下一轮 |
| Mr. White 被投出 | 他有 30 秒猜平民的词，猜对就是 Mr. White 赢 |
| 一局结束 | 留在同一个房间，大家再点 Ready 就开下一局，分数累计；掉线超过 1 分钟的人自动移出 |

## AI 玩家

人不够时，房主可以在大厅点 **+ Add an AI player** 补位。AI 玩家：
- 名字后面一律标 **(AI)**，大家都知道谁是机器人；
- 一直保持 Ready，但房间里至少要有一个真人才会开局，只剩 AI 时房间自动关闭；
- 用内置的联想词库出线索（每个词至少 5 个可用线索），**不用任何付费 API**；
- 当卧底时，如果发现自己的词和大家不一样，会故意说两个词都沾边的线索来伪装；
- 难度经过调试：第一轮就抓到卧底的概率约 4 成，Mr. White 猜中词约 7 成。

## Public / Private 房间

在首页创建房间时就选好类型，之后不能再改：
- **Create a private room**：只能通过房间码或邀请链接加入。
- **Create a public room**：出现在首页右侧的 "Public rooms" 列表里，任何人都能点进来。

## 界面

为电脑浏览器设计的宽屏布局：游戏时左边是你的词和当前操作，右边固定显示玩家状态和所有线索；窄屏（手机）自动变成单列。
统一使用简洁风格：浅灰底、白卡片、黑色文字，蓝色标出"轮到你 / 你的选择"，红色只用在倒计时快结束和出错提示。字体是 Inter，随网站一起部署，不依赖 Google Fonts。
首页不用填名字：先进房间，再在房间里填名字（也可以点 "Pick a random name"）。名字填好之前不能 Ready；这台设备下次会自动沿用，点自己名字旁的 Edit 可以改。

## 之前那些 bug 的处理

- **直接说出自己的词**：服务器会拦截。自己的词、单复数、包含关系（pancakes、cake ⊂ Pancake）、带重音的写法都提交不了。
- **规定说一个词，有人打一串**：有空格、符号、emoji、超过 20 个字母，或者别人已经用过的词，都提交不了。
- **白板第一个发言没东西可说**：改成给他类别提示。
- **投票规则不清楚**：每人 1 票，不能投自己，规则写在每个页面上。
- **结束后要回主页**：现在直接在同一个房间再来一局。
- **掉线**：重新打开网页会自动回到原来的位置，还是同一个词、同一张票。

## 部署到网上（免费，约 15 分钟）

用 **GitHub**（存代码）和 **Render**（运行网站），不需要写代码。

### 第 1 步：把代码放到 GitHub
1. 打开 github.com，注册并登录。
2. 点右上角 **+** → **New repository**，名字填 `undercover`，选 **Public**，点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**。
4. 把解压后文件夹里的**所有内容**拖进去：`server.js`、`rules.js`、`words.js`、`package.json`、`README.md`，以及 `public` 和 `test` 两个文件夹。
5. 点 **Commit changes**。

### 第 2 步：在 Render 上运行
1. 打开 render.com，选 **Sign in with GitHub**。
2. **New +** → **Web Service** → 选 `undercover` 仓库 → **Connect**。
3. 填写：
   - **Runtime**：Node
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
   - **Instance Type**：先选 **Free** 测试
4. 点 **Create Web Service**，等状态变成 **Live**。左上角的 `https://xxxx.onrender.com` 就是游戏网址。

### 免费版和正式上线
- 免费版 **15 分钟没人访问会休眠**，下次打开要等 30–60 秒，而且平台可能随时重启它，重启时进行中的房间会消失。自己测试或公司小范围玩没问题。
- **真正公开上线**，建议升级到 Render 的付费实例（Starter 约 $7/月），不会休眠。
- 服务器把房间存在内存里，**只能跑一个实例**。一台小机器同时撑几百个房间不成问题；以后人多了要扩容，需要加 Redis，到时候再改。

### 改词库
编辑 `words.js`，在对应的包里按 `["词A", "词B"],` 的格式加一行；也可以照着现有的格式复制一个包，新建自己的包（比如公司内部梗），它会自动出现在设置里。Mr. White 拿到的提示：基础包是细分类别，其他包是包名。在 GitHub 上提交后，Render 会自动重新部署。

```bash
npm test         # 58 项自动测试：规则、词库、AI 玩家、公开/私密房间 + 模拟多部手机完整对局
```
